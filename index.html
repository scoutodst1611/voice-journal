Voice Journal

Talk, type, or both. Each entry keeps your recording and its transcript together.

Google DriveNot connected. Entries are only saved in this browser.

This is a one-time setup that takes about five minutes. You add a small script to your own Google account. After that, every entry you save becomes a Google Doc, with its recording beside it, in a Voice Journal folder in your Drive. Edits update the Doc, and deleting an entry moves its files to Drive’s trash.

The script uses Google’s limited Drive permission, so Google only lets it see and change files the script created. Everything else in your Drive is off limits to it.

  1. Create a project. Open a new Apps Script project ↗ while signed in to your personal Google account. Click “Untitled project” at the top and rename it Voice Journal Sync.
  2. Paste the script. It already contains this journal’s private key. In the editor, select all of the sample code in Code.gs and paste the script over it. 
    
        
    3. 
        
  3. Paste the settings file. This is what limits the script’s access. In the left sidebar, click Project Settings (gear icon) and tick Show “appsscript.json” manifest file in editor. Go back to the Editor (the <> icon), open appsscript.json, select everything in it, and paste the settings over it. Click the Save icon.
          
    
            
            
          
    
          
    
        
    4. 
        
  4. Deploy it as a web app. Click Deploy → New deployment. Click the gear icon next to “Select type” and choose Web app. Check that Execute as is Me and Who has access is Anyone, then click Deploy. When asked, click Authorize access and pick your account. Google warns that the app isn’t verified because you made it yourself. Click Advanced, then Go to Voice Journal Sync (unsafe). The next screen should say the app can only reach “the specific Google Drive files that you use with this app”. Click Allow.
    5. 
        
  5. Paste the Web app URL and connect. Copy the URL that ends in /exec from the deployment screen.
          
    
            
            
          
    
        
    6.
